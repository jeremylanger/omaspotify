Never author/co-author commits.
At the end of each development step (a complete set of work), propose 3 git commit messages, but don't do the commit. Must be a maximum of 50 characters.
Use very minimal comments, typically only 1 line long.
Don't add dates to comments (e.g. "Decided on [date]").
Comments must be in plain english, no jargon.
Always use red/green TDD.
When a dependency doesn't behave as expected, research and test instead of jumping to writing custom code. All code is a liability. Lean towards having someone else maintain that liability.
When installing a dependency, always install the latest version pinned.
